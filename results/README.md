# AHIS Results

This directory separates deterministic software/HIL evidence from future physical measurements.

## `v3_extreme_campaign/`
Generated by `python scripts/run_v3_campaign.py`. It is **software/HIL-only** evidence and carries the authority:

`SOFTWARE_AND_HIL_ONLY__NO_PHYSICAL_HEALING_OR_HULL_SURVIVABILITY_CREDIT`

It cannot promote `PHYSICAL_STATUS.json`.

## Future physical P1 runs
`python scripts/p1_run_controller.py ...` writes physical run records under `results/physical/P1/` only when connected to live Pico hardware and supplied measured calibration artifacts. Each run binds its raw telemetry SHA-256 and calibration-bundle SHA-256.

Do not edit raw telemetry after capture. If processing changes are required, preserve the original file and create a new derived artifact. Physical promotion remains a deliberate human review process described in `docs/08_Physical_Acceptance_and_Promotion.md`.
