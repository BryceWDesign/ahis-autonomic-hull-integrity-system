# Source Traceability

The repository records web/provenance references in `provenance/TECHNICAL_BASIS_V3_2026.json`. The build intentionally relies on manufacturer specifications for component limits and on primary/reputable technical sources for repair-mechanism research framing.

Core examples:
- Raspberry Pi Pico 2 product information;
- Adafruit peristaltic pump, MOSFET driver, HX711 and load cell specifications;
- MPX5010 manufacturer data sheet for 0-10 kPa range and recommended decoupling;
- Pololu relay carrier and 5 V regulator data;
- AutomationDirect GCX1131 emergency-stop hardware;
- MilliporeSigma A2033 sodium alginate and C3881 calcium chloride dihydrate identities;
- NASA puncture-healing polymer and SMA/MMC research;
- peer-reviewed composite healing and SHM literature.

Repository descriptions paraphrase these sources. Manufacturer or paper performance is never copied into AHIS as measured AHIS performance.
