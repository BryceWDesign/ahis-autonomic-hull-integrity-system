# Productization Gap

AHIS v3 is a research testbed, not a field product. Moving toward a real structural system would require, at minimum:

- qualified material systems and manufacturing processes;
- environmental durability data;
- fatigue, fracture, corrosion/chemical compatibility and aging programs;
- redundant sensor architecture and verified diagnostics under realistic boundaries;
- qualified embedded electronics and power architecture;
- failure-tolerant repair-agent storage and distribution;
- maintainability and replenishment procedures;
- NDE correlation;
- formal hazard analysis and safety case;
- independent verification and applicable certification/authority approval.

This list is a boundary, not a promise that each item is sufficient.
